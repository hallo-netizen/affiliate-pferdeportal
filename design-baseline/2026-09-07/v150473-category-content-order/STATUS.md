# Pferde Atelier Design 1.50.473 – Kategorie-Reihenfolge

STATUS: CANDIDATE / NICHT LIVE

Ziel:
Die zentral gesteuerte Kategorieebene wird redaktionell neu geordnet.

Reihenfolge:
1. H1
2. Unterkategorie-/Beitragsart-Verweise
3. Kategorienartikel
4. Beitragsvorschau
5. kommerzielle Blöcke

Technik:
- eine zentrale Renderer-Funktion geändert;
- gilt automatisch für alle Seiten derselben strukturellen Kategorieebene;
- V104 unverändert;
- keine Inhalts-, Karten-, Auswahl- oder Affiliate-Regel geändert;
- main unverändert.

Abnahme:
Installation des Kandidaten und visuelle Prüfung auf „Gebisse“ plus mindestens einer weiteren Kategorie derselben Ebene.
