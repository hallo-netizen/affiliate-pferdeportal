## Regel

Neue PB-ONE-Arbeit muss nach Abschluss auffindbar sein.

Mindestens:
- eindeutige ID oder Titel;
- Bereich;
- Status;
- Hauptquelle;
- letzter relevanter Stand;
- ggf. Übergabe an Projekt/Büro.

Keine zweite Inhaltswahrheit im Zentralregister.
