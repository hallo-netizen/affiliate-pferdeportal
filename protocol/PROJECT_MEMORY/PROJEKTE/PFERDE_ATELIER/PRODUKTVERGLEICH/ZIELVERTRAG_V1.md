STATUS: ABGELÖST

NACHFOLGER:

## Historische Aussage

V1 beschrieb die frühere eigenständige Produktvergleichsstraße:

`Produktwissen -> Vergleichsdefinition -> gebundenes Dossier -> Zero-Freedom-Renderer -> Validator -> WordPress-DRAFT -> interne Linkbindung -> neutrale Vergleichsgrafik -> finaler Draft-Hash`

Diese Produktionsarchitektur ist **nicht mehr der aktive Zielweg**.

## Warum abgelöst

Die spätere verbindliche KISS-Entscheidung trennt:
- PRODUKTVERGLEICH = fachlich gebundenes Vergleichsdossier;
- SEO/TEXT = bestehende Textmaschine und Artikeltyp-Regeln;
- ACM = reine gebundene Orchestrierung;
- Affiliate = Commerce-Schicht.

Damit entsteht keine zweite parallele Textmaschine.

Für den aktuellen Zielstand ausschließlich `ZIELVERTRAG_V2.md` verwenden.
