Produktvergleich:
- exakt 2 konkrete Produkte;
- unterschiedliche Hersteller;
- gleiche sinnvolle Vergleichsklasse;
- keine Ersatzprodukte;
- keine erfundenen Produktfakten;
- Varianten sind keine separaten Vergleichspartner eines Produktvergleichs.

SEO-Freigabe:
- direkte belastbare Paar-Nachfrage A gegen B / vs / oder **oder**

- nur ein Produkt mit Nachfrage oder generische Gruppenanfrage reicht nicht;
