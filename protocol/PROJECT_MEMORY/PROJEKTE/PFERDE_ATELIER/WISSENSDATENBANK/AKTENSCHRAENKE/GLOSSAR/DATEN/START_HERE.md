# GLOSSAR – DATENABLAGE

Ein Begriff = ein Datensatz.

Pflicht: stabile ID, Begriff, Oberbereich, Definition, Quellen, Status. Fehlende Details werden offen gelassen; keine Vermutung. Synonyme sind keine separaten Datensätze.

Quellen folgen `../../../RECHERCHE_STANDARD.md`. Für Anatomie/Medizin möglichst Universität, Tierärztliche Hochschule oder wissenschaftliche Fachquelle; für Zucht-/Sporttermini zuständiger offizieller Verband bzw. Regelgeber.
