## 1-KLICK-ÜBERSICHT

**WAS IST DAS?**  
Die zentrale quellengebundene Fachbegriffs-Datenbasis des Pferde-Ateliers.

**HIER BIST DU RICHTIG, WENN …**  
ein Pferdefachbegriff erklärt, abgegrenzt, thematisch eingeordnet oder als Glossarkandidat geprüft werden soll.

**DU DARFST …**  
neue Begriffe quellengebunden anlegen, Synonyme pflegen, Ober-/Unterbereiche zuordnen, verwandte Begriffe verknüpfen und den späteren SEO-Prüfbedarf markieren.

**DU DARFST NICHT …**  
aus einem Glossarbegriff automatisch eine öffentliche URL oder einen Artikel erzeugen, Definitionen aus schwachen Quellen übernehmen oder SEO-Freigaben vorwegnehmen.

**ALS NÄCHSTES …**  
`GLOSSAR_STRUKTUR.md` → `GLOSSAR_REGISTER.md` → `DATEN/START_HERE.md`.

## GRUNDPRINZIP

Ein Begriff = ein Datensatz.

Dieser Aktenschrank bleibt die **alleinige Fachwahrheit** für Begriff, Definition/Fakten, Quellen, Synonyme, Einordnung und fachliche Relationen.

## PRODUKTIONSBRÜCKE

Für die öffentliche Glossarproduktion darf ein fachlich ausreichend geprüfter Datensatz als Quelle für folgenden Weg dienen:

`WDB-Datensatz -> Veröffentlichungsfassung im Chat -> JSON-Batch -> Glossar-Importer -> WordPress-Draft -> Readback`

Dabei gilt:
- der JSON-Batch ist nur Transport;
- WordPress ist nur Ausgabesystem;
- weder JSON noch WordPress dürfen hier gespeicherte Fachfakten still überschreiben;
- neue Fakten werden zuerst hier quellengebunden ergänzt/geprüft;
- ein Produktionsstatus in WordPress ist kein Recherche-/Fachstatus dieser WDB.

## ORGANISCHE ERWEITERUNG

Taucht während anderer Recherche ein wichtiger Fachbegriff auf, darf er als Glossarkandidat vorgemerkt werden. Ein Datensatz wird erst angelegt, wenn der Begriff tatsächlich recherchiert und belegt wird.
