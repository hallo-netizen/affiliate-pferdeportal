# PFERDERASSEN – DATENABLAGE

STAND: 2026-09-12

## 1-KLICK-ÜBERSICHT

**WAS IST DAS?**  
Die Ablage der einzelnen quellengebundenen Rassendatensätze.

**HIER BIST DU RICHTIG, WENN …**  
eine konkrete Rasse nach formaler Statusprüfung recherchiert oder ergänzt wird.

**DU DARFST …**  
pro Rasse genau einen strukturierten Datensatz nach `../RASSEN_DATENMODELL.md` pflegen.

**DU DARFST NICHT …**  
Synonyme duplizieren, schwache Quellen als harte Fakten behandeln oder fehlende Felder erraten.

**ALS NÄCHSTES …**  
`../RASSEN_DATENMODELL.md` und `../RASSEN_REGISTER.md` prüfen, danach den konkreten Datensatz bearbeiten.

## ABLAGE

- bevorzugt JSON;
- stabile interne ID;
- `schema_version` je Datensatz;
- Quellen/Faktzuordnung erhalten;
- Pferd/Pony/Kleinpferd ist Klassifikation, kein eigener Datenraum.
