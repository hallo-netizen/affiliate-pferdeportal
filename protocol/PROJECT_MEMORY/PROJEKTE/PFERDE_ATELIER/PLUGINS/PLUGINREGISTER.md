## LEGENDE

- **KRITISCH** = Kern-/Produktions-/Sicherheitsfunktion; nicht ohne Fachprüfung verändern.
- **WICHTIG** = aktive wesentliche Funktion; behalten, außer Fachprüfung ergibt etwas anderes.
- **PRÜFEN** = Zweck/Overlap/Abhängigkeit/aktueller Status muss vor Entscheidung geklärt werden.
- **HILFSWERKZEUG** = Audit/Diagnose/Export/Adminhilfe; nicht automatisch dauerhaft nötig.
- **AUFRÄUMKANDIDAT** = plausibel entbehrlich/abgelöst/inaktiv, aber **keine Löschfreigabe**.

`EIGEN` bedeutet: im Pferde-Atelier-/OpenAI-/Workflow-Automation-Projektweg als Eigen-/Projektentwicklung entstanden; keine Aussage über juristische IP-Rechte.
