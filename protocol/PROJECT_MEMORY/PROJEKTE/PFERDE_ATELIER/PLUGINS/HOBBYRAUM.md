## WENN EIN UPDATE BEAUFTRAGT WIRD

Der Hobbyraum bindet genau:

- Plugin-ID aus `PLUGINREGISTER.md`;
- zuständiges Fachbüro;
- beobachtete Ausgangsversion;
- Zielversion/Updatequelle;
