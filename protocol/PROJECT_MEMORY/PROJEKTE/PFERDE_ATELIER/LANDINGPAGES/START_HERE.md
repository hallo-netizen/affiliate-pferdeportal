## 1-KLICK-ÜBERSICHT

**WAS IST DAS?**  
Das Konzept- und Steuerbüro für eigenständige Landingpages im Pferde-Atelier.

**HIER BIST DU RICHTIG, WENN …**  
eine Seite ein konkretes Vergleichs-, Rechner-, Such- oder Angebotsziel verfolgt und bewusst nicht als normale Produktionskategorie oder normaler Journalartikel geführt werden soll.

**DU DARFST …**  
Landingpages planen, ihre Suchintention abgrenzen, die sichtbare Einbindung in vorhandene Portalbereiche definieren und Provider-/Rechner-/Bannerbedarf an die zuständigen Fachbüros binden.

**DU DARFST NICHT …**  
die zentrale Kategorienwahrheit verändern, eine Landingpage als Fake-Kategorie anlegen, TEXT/PSERC/PSTE umgehen, Plugin-Governance umgehen oder Provider-/Designlogik hier als zweite technische Wahrheit führen.

**ALS NÄCHSTES …**  
`protocol/PROJECT_MEMORY/AUTORITAETSPLAN.json` → Scope `PFERDE_ATELIER_LANDINGPAGES` → genau eine Current-Autorität → Frischecheck → deren NEXT ACTION.

## Harte Fachgrenze

- **Kategorie** = normale Portal-/SEO-Struktur mit Artikelproduktion.
- **Journalartikel** = redaktioneller Informationsbeitrag der normalen Textproduktion.
- **Landingpage** = normale WordPress-Seite mit eigenem Transaktionsziel, z. B. Rechner, Vergleich oder Suche.
- Eine Landingpage darf im Frontend wie eine normale Themenkachel aussehen, bleibt intern aber eine Seite und wird nicht zur WordPress-Kategorie.
- Affiliate-/Providerdaten bleiben ausschließlich im AFFILIATE-Büro.
- Darstellung/Templatecode bleibt ausschließlich im DESIGN-Büro.
- Kategorienwahrheit bleibt ausschließlich im zentralen Kategorienweg.
- Textmaschinenregeln bleiben ausschließlich im TEXT-Büro.
