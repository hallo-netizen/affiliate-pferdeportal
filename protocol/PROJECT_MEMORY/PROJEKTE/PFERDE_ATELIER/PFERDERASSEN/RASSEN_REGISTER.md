# PFERDERASSEN – REGISTER

STAND: 2026-09-12
STATUS: INITIALISIERT

## ZWECK

Dieses Register ist der zentrale Wegweiser zu allen recherchierten Pferde-, Pony- und Kleinpferderassen.

Es enthält keine vollständigen Fachinhalte und keine zweite Rassenwahrheit. Die eigentlichen Datensätze liegen unter `DATEN/`.

## STATUSWERTE

- `ANGELEGT` – Datensatz existiert, Recherche noch nicht vollständig
- `IN_RECHERCHE` – aktive Quellenrecherche
- `GEPRUEFT` – Kernfelder und Quellen geprüft
- `NACHRECHERCHE` – neue Schemafelder oder offene Konflikte müssen nachgezogen werden
- `BEITRAG_BEREIT` – Faktenbasis für Textproduktion fachlich ausreichend

## REGISTER

Noch keine Rassendatensätze eingetragen.

## REGELN

- eine Rasse = ein Registereintrag = ein Datensatz;
- Synonyme erzeugen keinen zweiten Datensatz;
- Ponyrassen stehen im selben Register wie Großpferderassen;
- neue Datensätze verwenden die Struktur aus `RASSEN_DATENMODELL.md`;
- Registerstatus ersetzt keine Quellenprüfung;
- vollständige internationale Abdeckung darf erst behauptet werden, wenn die Masterliste separat geprüft wurde.
