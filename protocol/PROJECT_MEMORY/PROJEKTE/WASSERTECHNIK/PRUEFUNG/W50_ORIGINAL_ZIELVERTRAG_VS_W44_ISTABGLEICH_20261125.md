1. Freigabe eigenständiger SEO-Seitenowner für 81 neue Kandidaten (besonders die 2 dokumentierten Überschneidungen); eine gezahlte Keywordabfrage ist keine freigegebene SEO-Seite. Bereits angelegte **Entwürfe nicht löschen und nicht massenhaft veröffentlichen**, sondern fehlenden Freigabestatus transparent halten.
2. Nachweisbare sichtbare Produkt-zu-Beitragskategorie-Verknüpfung in der Produktansicht und Validierung dieser Beziehungen.

4. HTTP-301-Weiterleitungen für alle wirklich migrierten veröffentlichten Altadressen; Zielstatus prüfen, keine Redirect-PASS-Aussage ohne HTTP-Beleg.
5. Die beiden übrigen Portal-Säulen Journal/Glossar und HivePress bleiben eigene Vorhaben.
