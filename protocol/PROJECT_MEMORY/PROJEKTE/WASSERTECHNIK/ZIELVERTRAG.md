# Wassertechnik – fachlicher Zielvertrag (Neuprojekt)

- Kommerzielles Affiliate-/Branchenportal; keine eigene Warenabwicklung.
- Drei eigenständige Säulen: (1) Hauptkategoriebaum und Beiträge, (2) Journal/Magazin + optionales Glossar, (3) Hilfe, Anbieter-/Anzeigenmarkt mit HivePress. Hilfe/FAQ gehört thematisch zum Journal, nicht als redundanter Produktbaum.
- WordPress-Core unverändert; KISS; kein zweiter Kategorie-Schreiber; nur ein aktives Design; neue Website getrennt von allen existierenden Portalen.
- Inhalte entlang konkreter Nutzer- und Kaufabsichten; Hauptpartner Amazon, eBay, idealo, OTTO, ergänzt um fachlich passende Affiliateprogramme.
- Bestehender Archivplan ist Entwurf: 8 Content-Hauptbereiche, 69 Content-Blätter, 26 Marketplace-Blätter, 6 Magazinrubriken, 20 Glossarbegriffe. Erst fachliche Prüfung dann Freigabe.
- Noch keine Website-Domain oder aktive WordPress-Instanz gebunden. Niemals einen fremden Produktionsbestand als Test verwenden.
- Keine automatische Rechts-, Trinkwasser- oder Sicherheitsbehauptung ohne zeitnahe Fachquellenprüfung.
- Bearbeitungsreihenfolge: Originalsortierung → unabhängige Fachprüfung → Kategorie-Owner und Beitragspotenzial → technische Adapterprüfung → Dry-Run → manuelle Freigabe → Live-Implementierung.
