## KISS – zentrales Roboterbüro

Jeder Fund bekommt **nur ein Label**: **Produkt** (tatsächlich angeboten), **Projekt** (real untersucht/gebaut/vorgeführt), **Idee** (Patent, Konzept, Studienarbeit ohne belegtes funktionsfähiges Gerät). Dazu eindeutige Fund-ID, Urhebertext, Beleg und Datum, ein Haupt-Robotertyp als Besitzer. Keine monatlichen Nachprüfungen; neue Fakten aktualisieren denselben Fund.

**Register** = einzelne Modelle/Patente/Versuche; **Fachbaum** = konkrete Robotertypen; **Magazin** = Entwicklungen; **Glossar** = Begriffe; **Finder** = Suche über dieselben Datensätze. Keine Parallel-Master und keine neue Liste in WordPress.
