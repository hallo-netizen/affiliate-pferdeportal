## Hierarchieregel – verbindlich
**Haupt-WP-Seite → ggf. mehrere weitere WP-Seiten → letzte WP-Seite = ein funktional klarer Robotertyp → dessen flache, individuelle WordPress-Inhaltskategorien → spätere Beiträge.**

- Hauptwelten und Zwischenbereiche sind WordPress-*Seiten*, niemals WordPress-Taxonomien.
- Ein Roboter darf nur **eine** produktbezogene CORE-Zielseite haben. Einsatzorte erzeugen alternative Einstiege/Links, nicht zusätzliche URLs für dieselbe Funktion.
- Eine Unterseiten-Kategorie entsteht nur, wenn mindestens **drei unterscheidbare mögliche Beiträge** zu genau diesem Robotertyp existieren. Keine global für alle Produkte erzwungene Rubrik „FAQ“, „Kosten“ oder „Vergleich“.
- Was eine Roboterbauart statt einer Aufgabe beschreibt, wird überprüft: etwa SCARA, Delta, Cobot, humanoid. Was nur eine Branche beschreibt, ist eher eine Zwischenseite.
- Anzeigen und Journal haben **andere Suchaufgaben** und keine doppelten Produktseiten.
