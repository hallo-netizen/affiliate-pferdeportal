## Fachliche Schranken
Eine letzte CORE-Seite = konkreter Robotertyp/Produkt. Darunter ausschließlich **flache WP-Kategorien**, die mindestens **3 unabhängig sinnvolle zukünftige Beiträge** (typisch 3–5 oder mehr) zu genau diesem Produkt tragen können. Für 1–2 Themen **keine** neue Kategorie. Die 151 Ideen sind **nicht als freigegebene WordPress-Kategorien** zu behandeln; Anzahl ist kein Qualitätsbeweis. Magazin-Fragen, einzelne Hersteller-Modelle, echte Anbieter und Glossardefinitionen dürfen CORE nicht duplizieren.
