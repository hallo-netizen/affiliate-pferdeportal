**Ziel:** Hersteller-Modelle analog zu Pferderassen/Hobbyprofilen anhand einer wiederholbaren Form vorstellen: Hersteller, genaues Modell, Einsatzfunktion, passende individuelle technische Daten, Quellen/Prüfdatum, verwandte Modelle, CORE-Robotertyp-Link. Eine Modellidentität darf mehrere Funktionen besitzen. Keine Hersteller-Modelle als zusätzliche CORE-Produktseiten oder pauschal als empfehlenswerte Affiliateprodukte klassifizieren.

**Getrennt:** Das schon vorhandene WISSENSDATENBANK/ROBOTERREGISTER definiert **Eigenschaften der Robotertypen**. Dieses Magazinbüro präsentiert später **konkrete Hersteller-Modelle**. Unterschiedliche Gegenstände, keine doppelte Typenliste.
