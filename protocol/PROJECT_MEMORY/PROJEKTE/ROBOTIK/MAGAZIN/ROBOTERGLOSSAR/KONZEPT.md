# Roboter-Glossar – bewährtes Portalmodell

**Originalvorbilder:** Pferdeatelier/WISSENSDATENBANK/GLOSSAR_STRUKTUR, Hobbydepot/GLOSSAR/KONZEPT_GLOSSAR, Hab-&-Bewahr/GLOSSAR_STRUKTUR. Es gelten A–Z, eigene Suche, ggf. Themenfilter, Paginierung als **eine** Glossarhauptseite; keine neue separate Seitenhierarchie je Filter.

**Einzelseite nur** bei eigenständiger Suchabsicht „Was bedeutet X?“, nicht bei vollständigen Robotertypen/Kaufberatungen oder bloßen Synonymen. Kurzdefinition, individuelle Erklärung, Abgrenzung, verwandte Glossarbegriffe, belegte Quellen und eine echte Hauptzielverknüpfung. Kein Copy/Paste von ISO-Normtexten. Zwischenbegriffe wie SCARA/Delta/AMR erst gegen CORE prüfen; im Zweifel nur Alias/verlinkte Kurzdefinition.

Daten: `term_id, begriff, synonyme, owner, definition, related, quelle, pruefdatum, pruefstatus`. 35 initiale **Kandidaten, noch keine 35 vollständigen Seiten**. ISO/DIS 8373 (2026) **Entwurf**, nicht als Ersatz der veröffentlichten ISO 8373:2021 ausgeben.
