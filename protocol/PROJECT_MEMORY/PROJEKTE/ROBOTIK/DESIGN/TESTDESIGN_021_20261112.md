# Robotik – Testdesign 0.2.1, 12.11.2026 – Korrektur nach Live-Screenshot

## Ausgangslage
Der Nutzer zeigte die real installierte 0.2.0-Testdarstellung auf robotik.oliver-beil.de. Dort erschienen die alten WordPress-Theme-Inhalte ("Nichts gefunden", "Neueste Beiträge", "Neueste Kommentare") zwischen Plugin-Kopfzeile und der angehängten Kategorieübersicht. Gewünscht ist ausschließlich ein monochromer Header mit 7 Hauptkategorien, funktionsfähigem Mega-Menü und klar erkennbarem Footer.

## Umsetzung
- Dieselbe Pluginidentität `robotik-strukturdesign`, Version **0.2.1** (Update für 0.2.0, keine weitere Design-Pluginlinie).
- Auf **der WordPress-Startseite** wird durch `template_include` eine eigene, absichtlich leere, minimale Layoutdatei genutzt; reguläre Theme-Blogansicht und Sidebars fallen dort weg. Andere WP-Seiten behalten die vorhandenen Theme-Vorlagen.
- WordPress-Funktionen `wp_head`, `wp_body_open`, `wp_footer` bleiben erhalten. Header und Footer werden exakt einmal gerendert.
- Sieben Hauptwelten aus `_robotik_kategorie_node_id`-markierten **realen** WP-Seiten; Industrie ist unter Gewerbe grau abgesetzt. Footer nutzt dieselben sieben echten Bereiche, linkt nur existierende Ziele.
- Desktop-Mega-Menü: Browser verbirgt Inhaltsknoten geschlossener `<details>` auch dann, wenn CSS sie öffnen soll. `mouseenter` setzt nun das echte `open`-Attribut; Klick, Escape, Mobil bleiben unterstützt.
- Schwarz, Weiß und Grau, keine Fotos, keine Kategorie-/Beitrags-Schreibvorgänge, keine Pluginverdopplung.
- **Das Kategorie-Plugin 0.4.2 (DataForSEO) wurde NICHT geändert.**
