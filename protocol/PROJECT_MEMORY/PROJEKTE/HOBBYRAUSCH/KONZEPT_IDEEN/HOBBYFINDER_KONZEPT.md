# Hobby Depot – Hobbyfinder-Konzept

Stand: 2026-10-02  
Status: KONZEPT / BRAINSTORMING – noch keine technische Umsetzung und keine Current-Autorität

## Grundidee

Der Hobbyfinder wird ein eigener, deutlich sichtbarer Einstieg in Hobby Depot. Er hilft Menschen, die noch kein konkretes Hobby im Kopf haben, passende Hobbys zu entdecken.

Wichtiges KISS-Prinzip: Es gibt **nur einen zentralen Hobby-Datenbestand**. Jedes Hobby erhält möglichst viele einheitliche Eigenschaften. Daraus werden alle Filter, Empfehlungen, Finder-Ergebnisse und später gegebenenfalls SEO-Landingpages abgeleitet.

Der Hobbyfinder arbeitet auf zwei Wegen, aber mit denselben Daten.

## Weg 1 – Geführter Hobbyfinder / Trichter

Der Nutzer wird mit wenigen einfachen Fragen Schritt für Schritt geführt. Er muss keine Hobbybegriffe kennen.

Mögliche Fragen:
- Wo? Drinnen / draußen / beides
- Mit wem? Alleine / zu zweit / Familie / Gruppe
- Was möchtest du tun? Bauen & machen / gestalten / bewegen / beobachten / sammeln / forschen / lernen
- Wie soll es sich anfühlen? Ruhig / aktiv / kreativ / knifflig / abenteuerlich / entspannend
- Wie viel Platz ist vorhanden? Kaum Platz / Tisch oder Arbeitsplatz / eigener Raum / draußen
- Wie hoch darf der Einstieg sein? Günstig / mittel / ausrüstungsintensiv
- Wie viel Zeit? Spontan / regelmäßig / längere Projekte
- Wann? Ganzjährig / Sommer / Winter / abends / Wochenende

Ergebnis: kleine, passende Auswahl mit kurzer Begründung, warum die Hobbys zu den Antworten passen.

## Weg 2 – Offene Entdecker-Übersicht

Alle wichtigen Unterscheidungskriterien sind auf einen Blick sichtbar. Der Nutzer kann frei kombinieren und direkt stöbern.

Beispiele für große Einstiege:
- Alleine
- Zu zweit
- Mit mehreren
- Mit der Familie
- Drinnen
- Draußen
- Kreativ
- Bauen & Machen
- Beobachten
- Sammeln
- Forschen
- Bewegung
- Wenig Platz
- Günstiger Einstieg
- Für den Winter
- Für den Sommer
- Ruhig & konzentriert
- Aktiv & körperlich
- Ungewöhnliche Hobbys

Die Auswahl wirkt wie ein einfacher Shop-Filter, aber für Hobbys.

## Optionaler dritter Einstieg – „Überrasch mich“

Sehr kleiner Inspirationsmodus. Der Nutzer wählt nur wenige Vorlieben aus und bekommt ungewöhnliche oder unerwartete Hobbys vorgeschlagen.

## Zentraler Hobby-Eigenschaftsbestand

Jedes Hobby bekommt einmal eine möglichst vollständige Merkmalszuordnung. Diese Eigenschaften werden nicht mehrfach in verschiedenen Systemen gepflegt.

Erste Merkmalsgruppen:
- Ort: drinnen / draußen / beides
- Sozialform: alleine / zu zweit / Gruppe / Familie
- Aktivität: bauen / machen / gestalten / bewegen / beobachten / sammeln / forschen / lernen
- Charakter: ruhig / aktiv / kreativ / technisch / handwerklich / naturbezogen / analytisch / abenteuerlich
- Platzbedarf: minimal / Arbeitsplatz / eigener Raum / Außenfläche
- Einstiegskosten: niedrig / mittel / hoch
- laufende Kosten: niedrig / mittel / hoch
- Zeitaufwand: spontan / regelmäßig / projektorientiert / langfristig
- Saison: ganzjährig / Sommer / Winter / saisonabhängig
- Tageszeit: flexibel / tagsüber / abends / Wochenende
- Mobilität: zuhause / mobil / ortsgebunden
- körperlicher Anspruch: gering / mittel / hoch
- Lernkurve: leicht / mittel / anspruchsvoll
- Ergebnisart: Objekt / Erlebnis / Sammlung / Wissen / Bewegung / Naturbeobachtung
- Ausrüstungsbedarf: gering / mittel / hoch
- Kinder-/Familientauglichkeit: ja / bedingt / nein
- Paar-/Gruppentauglichkeit: ja / bedingt / nein

Die Liste darf später erweitert werden. Wichtig ist nur: zentrale Eigenschaften, keine parallelen Listen.

## Verhältnis zur normalen Navigation

Der Hobbyfinder ersetzt die normale SEO-/Hobby-Navigation nicht.

- Navigation: Nutzer kennt ein Hobby oder Thema und geht gezielt hinein.
- Hobbyfinder: Nutzer kennt sein Hobby noch nicht und sucht Orientierung.

Beide Wege führen am Ende auf dieselben Hobbyseiten und Kategorien.

## Abgrenzung zum Magazin

Der Hobbyfinder ist ein **Werkzeug zur Auswahl und Orientierung**. Er beantwortet die Frage: „Welches Hobby passt zu mir?“

Das Magazin ist **redaktionell und inspirierend**. Es beantwortet Fragen wie:
- Welche ungewöhnlichen Hobbys gibt es?
- Welche Hobbys eignen sich im Winter?
- Welche neuen Trends gibt es?
- Was kann man als Paar ausprobieren?
- Was steckt hinter einem bestimmten Hobby?

Damit gilt:

**Hobbyfinder = Auswahlmaschine**  
**Magazin = Inspiration, Geschichten, Ratgeber und SEO-Einstiege**

Beide dürfen sich sinnvoll ergänzen. Ein Magazinartikel wie „10 Hobbys für zwei“ kann direkt in den Hobbyfinder mit dem Filter „zu zweit“ führen. Der Hobbyfinder kann umgekehrt passende Magazinartikel anzeigen.

## SEO-Zusammenspiel

Filterkombinationen werden nicht automatisch alle zu indexierbaren Seiten.

Nur wenn DataForSEO für einen Filter-/Intent-Raum echte Suchnachfrage zeigt, kann daraus eine eigene SEO-Landingpage entstehen, z. B.:
- Hobbys für zuhause
- Hobbys im Winter
- Hobbys alleine
- Hobbys zu zweit
- Hobbys draußen
- kreative Hobbys

So bleibt der Finder frei kombinierbar, ohne tausende dünne SEO-Seiten zu erzeugen.

## Sichtbarkeit auf der Website

Der Hobbyfinder soll als eigenständiger, gut sichtbarer Zugang behandelt werden.

Mögliche Platzierungen:
- eigener Hauptnavigationspunkt „Hobbyfinder“
- zusätzlich prominenter Einstieg auf der Startseite
- optional kompakter Link in der Topbar
- zusätzlicher Link im Footer

Bevorzugte Denkweise: Hauptnavigation/Startseite für Sichtbarkeit; Footer nur ergänzend.

## KISS-Zielbild

Ein Datenbestand → viele Eigenschaften → zwei Finder-Oberflächen → dieselben Hobbys → dieselben Zielseiten.

Keine zweite Hobby-Datenbank. Keine getrennte Pflege für Trichter, Übersicht und SEO. Das System soll später beliebig neue Filterwege ermöglichen, ohne die Hobbys neu erfassen zu müssen.

## Noch offen / bewusst nicht entschieden

- exakte Anzahl und Reihenfolge der Trichterfragen
- endgültige Merkmalsliste
- Gewichtung der Eigenschaften bei Empfehlungen
- Darstellung der Treffer und eventuelle Prozentwerte
- endgültige Position des Hobbyfinders in Hauptnavigation/Topbar/Footer
- genaue Grenze, wann eine Filterkombination eine eigene SEO-Landingpage erhält

Diese Punkte bleiben bewusst offen, bis Navigation und zentraler Hobby-Datenbestand feststehen.
