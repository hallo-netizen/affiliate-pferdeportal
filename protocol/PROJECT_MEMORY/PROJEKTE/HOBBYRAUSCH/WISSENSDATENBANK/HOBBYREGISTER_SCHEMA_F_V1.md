# HOBBY DEPOT – HOBBYREGISTER – SCHEMA F V1

STAND: 2026-10-22
STATUS: VERBINDLICHER SEITENVERTRAG

## Grundregel

Jede Hobbyseite im Register folgt derselben Grundstruktur und wird aus genau einer kanonischen Hobbyidentität, dem zentralen 57er-Eigenschaftsschema und dem vorhandenen 4-Felder-Kurzprofil erzeugt.

Nicht alle 57 Merkmale werden als Tabelle ausgegeben. Sie sind gemeinsame Datenbasis, Vergleichslogik und Rohstoff für verständlichen Fließtext.

## F1 – Sofort verstehen

- Hobbyname
- Was ist das?
- Was macht man?
- Was ist der Reiz?
- kurze Einordnung: klassisch / Nische / ungewöhnlich / sehr schräg

## F9 – Kompakter Vergleichsblock

Für die schnelle Vergleichbarkeit werden sichtbar verdichtet:
- alleine / gemeinsam
- drinnen / draußen
- typische Zeit
- Einstiegsbudget
- Platzbedarf
- körperliche Intensität
- Kraftbedarf
- Koordination / Balance
- Lernkurve
- Spontanität / Bindung
- ungewöhnlich / klassisch

Weitere Eigenschaften dürfen kontextabhängig ergänzt werden, aber keine 57-Felder-Wand.

## F10 – Ähnliche Hobbys

Ähnliche Hobbys werden aus dem zentralen Traitbestand abgeleitet.
Keine neue Hobby-Taxonomie und keine zweite Datenpflege.

## Textregel

Die Hobbyseite wird nicht als ausgefülltes Formular geschrieben.
Die Merkmale werden in natürliche, hobbybezogene Absätze übersetzt.
Keine generischen Fülltexte.
Keine Behauptung bei UNKNOWN.
Widersprüche zwischen Traits müssen vor Veröffentlichung blockieren.

## SEO-Abgrenzung

Die SEO-Sichtbarkeit wird getrennt von Schema F gesteuert.
Schema F gilt identisch für CORE-nahe und reine Register-/Nischenhobbys.
Wenn eine starke CORE-Hauptseite dasselbe Hobby bzw. dieselbe Suchabsicht besitzt, bleibt das Registerprofil für Nutzer vollständig erhalten, wird aber als konkurrierende Google-Zielseite unterdrückt.
Im Zweifel hat die CORE-Hauptseite Vorrang.
