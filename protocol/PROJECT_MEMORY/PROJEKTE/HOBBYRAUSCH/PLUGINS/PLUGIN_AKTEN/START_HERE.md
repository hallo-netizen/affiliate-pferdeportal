# HOBBYRAUSCH – PLUGIN-AKTEN

## 1-KLICK-ÜBERSICHT

**WAS IST DAS?**  
Der zentrale Aktenschrank für alle Hobbyrausch-Plugins.

**HIER BIST DU RICHTIG, WENN …**  
du ein konkretes Plugin suchst oder neu anlegst.

**DU DARFST …**  
für jedes Plugin genau eine feste Plugin-ID anlegen.

**DU DARFST NICHT …**  
mehrere Current-Dateien für dasselbe Plugin führen oder Originale überschreiben.

**ALS NÄCHSTES …**  
Plugin-ID wählen → dessen `START_HERE.md` → `CURRENT.md`.

## Pflichtstruktur je Plugin

```
<PLUGIN-ID>/
├── START_HERE.md
├── CURRENT.md
└── ORIGINAL/
    └── START_HERE.md
```

`ORIGINAL/` enthält die unveränderten Originaldateien des belegten Pluginstands.
