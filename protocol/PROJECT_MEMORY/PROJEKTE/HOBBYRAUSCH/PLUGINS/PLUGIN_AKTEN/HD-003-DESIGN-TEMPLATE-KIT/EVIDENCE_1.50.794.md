## Technischer GitHub-Zustand – entscheidend

**Das vollständige 65,7-MB-Plugin ist NOCH NICHT als binäre ZIP in GitHub angekommen.**
Die verfügbaren GitHub-Connector-Aktionen können textbasierte Repositorydateien und Git-Blobs aus übergebenem Text/Base64 schreiben, aber **sie können eine vorhandene lokale Datei `/mnt/data/...` nicht direkt als GitHub-Binärdatei übernehmen**. Der aktuelle Ausführungscontainer kann `github.com` nicht per HTTPS erreichen. Darum ist eine über diese Verbindung vorgetäuschte ZIP im Repo untersagt. Die zuvor vorgeschlagene ChatGPT-Bibliothek ist nicht das gewünschte **GitHub-Pluginbüro** und ersetzt diese Ablage nicht.
