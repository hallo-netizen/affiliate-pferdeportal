### Pflicht-Prüfbereiche je Hobby

Für jedes Hobby müssen mindestens geprüft werden:
- Einstieg;
- Ausrüstung;
- Material;
- Techniken/Praxis;
- Fragen/Probleme;
- FAQ.

`Einstieg` muss Fragen zu Anfänger-Eignung, Vorwissen, Schwierigkeit, Zeit, Platz, Kosten, Startbedarf und ersten Schritten abdecken.

`FAQ` ist für Hobby Depot als Pflichtkategorie gewünscht, darf aber keine bereits anderweitig belegte Suchintention duplizieren.

Grundregel:
**Jeder Beitrag besitzt genau einen eindeutigen Intent-/Keyword-Owner.**
