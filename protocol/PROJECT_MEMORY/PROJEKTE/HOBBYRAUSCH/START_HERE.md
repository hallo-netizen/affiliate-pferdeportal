## EINE WAHRHEIT

Für jedes Büro:
`START_HERE → AUTORITAETSPLAN → genau eine Current-Autorität → Frischecheck → NEXT ACTION`.

Für jedes einzelne Plugin:
`PLUGINS/PLUGIN_AKTEN/<PLUGIN-ID>/CURRENT.md` = einzige aktuelle Plugin-Wahrheit.

Unveränderte Originaldateien:
`PLUGINS/PLUGIN_AKTEN/<PLUGIN-ID>/ORIGINAL/`.

Register, Historie, Originaldateien und Hobbyraum dürfen niemals zweite Current-Wahrheiten werden.
