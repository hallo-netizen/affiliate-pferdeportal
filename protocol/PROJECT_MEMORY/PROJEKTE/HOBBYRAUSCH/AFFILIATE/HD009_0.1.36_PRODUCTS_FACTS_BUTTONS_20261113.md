# HD009 0.1.36 – Belegte Produktrelevanz, echte Kurzmerkmale und Mehranbieter-Karten

Datum 13.11.2026. Vollversion, aus exakt CURRENT 0.1.35 aufgebaut, darunter enthält die Basis auch 0.1.34 sicheren Feedvergleich. Nur eine bestehende PHP-Hauptdatei geändert; kein neuer Import, keine DB-Tabelle, keine Frontend-API, kein WordPress-Core, keine fremden Portale.

Belegter Livefehler: Auf Hobby Depot /gestalten/malen-zeichnen/airbrush/ standen zwei Damenbekleidungsprodukte mit Modellname Malene und Cotton Batik. Der 0.1.35 Zielpfad war allein nicht ausreichend; die neuen Regeln verlangen nun zusätzlich **direkte Hobbybegriffe im tatsächlichen konkreten Produkttitel** (nur Idealo auf WordPress-Hobbyseiten). Malene ist nicht Malen, Gründl Cotton Batik nicht Airbrush. Andere Provider werden nicht verändert; Artikel, Banner, GTIN und iPN-API bleiben bestehen. Wenn kein sicher passendes Produkt existiert, darf der Slot leer bleiben.

Produktkarte: Der vorhandene Kategorie-Produkt-HTML-Aufbau hat nun Bild über Titel/Text statt nebeneinander: inline grid columns exakt eine Spalte. Die Karte kann bereits vorhandene Mehrfachanbieter-Buttons von multiprovider_matching_offers_for_banner weiter ausgeben. Wenn der Produktname wörtlich eine Maßangabe, Farbe, Material, Set oder konkreten Typ enthält, gibt es 1-3 kurze Fakten unter "Auf einen Blick". Keine erfundenen Spezifikationen.
