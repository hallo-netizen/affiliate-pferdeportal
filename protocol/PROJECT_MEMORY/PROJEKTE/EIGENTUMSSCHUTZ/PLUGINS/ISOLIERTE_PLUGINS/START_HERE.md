# HAB & BEWAHR – ISOLIERTE VOLL-ZIPS

Ein Plugin pro unverändertem Plugin-Ordner unter seiner HAB-ID; nur die aktuelle **vollständige binäre Installations-ZIP** heißt `CURRENT.zip`. MANIFEST ist bloßer Abruf-/Prüfnachweis, keine zweite Current-Autorität. Ein `CURRENT.zip`-Platzhalter ist verboten. Fehlender wirklicher Bytebestand = BLOCKED.
