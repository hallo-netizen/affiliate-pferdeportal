# HAB & BEWAHR – TECHNISCHE EIGENPLUGIN-AKTEN

Hier stehen die einzigen aktuellen technischen Akten für die unter `../REGISTER.md` registrierten Eigenplugins. Die Office-Current koordiniert ausschließlich das Bürogate. Jede Plugin-Akte besitzt genau eine eigene `CURRENT.md`; die ZIP-Ablage führt in `../ISOLIERTE_PLUGINS/` und darf keine eigene Versionswahrheit erzeugen. Keine Fremdplugins.
