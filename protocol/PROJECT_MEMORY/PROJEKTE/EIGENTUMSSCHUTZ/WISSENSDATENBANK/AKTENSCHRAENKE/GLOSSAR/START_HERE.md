# HAB & BEWAHR – GLOSSARBÜRO
**Quelle:** Aus dem echten `PFERDE_ATELIER/WISSENSDATENBANK/AKTENSCHRAENKE/GLOSSAR/` übernommen und fachlich angepasst – kein zweites Pferde-Atelier im Kleinen.

**Zweck:** Recherchierte Erklärungen von Fachwörtern zu privater Eigentumssicherung, Schutz kleiner persönlich geführter Objekte und typischen Schäden. Ein Begriff = eine Glossarakte.

**KEIN eigenständiger Statusraum:** Eine gültige [Current-Autorität](../../CURRENT_STATE.md) für das ganze Wissensbüro. Hier nur der feste Fachvertrag.

**Glossaraufnahme:** Hauptintention muss Fachbegriffserklärung sein; bloße Suchthemen, zentrale Hub-/Kategorienamen, starke Vergleichs- und Ratgeberthemen sind keine eigenen Glossar-Doppel-Seiten. Exakter aktiver WP-Kategoriename als Begriff = Ausschluss (wie beim Vorbild); Synonyme werden Aliase, keine zweiten URLs.

**Beziehungen:** genau eine primäre Schutzwelt, mindestens ein verwandter Begriff; optional genau eine tatsächlich vorhandene starke Hauptseite, Vorrang den zentralen Schutzkategorien vor Magazin. Niemals URL erfinden.

**Research+Text:** einmaliger Quellenworkshop 150–200 Wörter, individuell formuliert, Definition+Einordnung+Abgrenzung, keine Bodylinks, SEO-Title+Description, Quellen/Prüfdatum, kein Keyword-Stuffing. Bei Unsicherheit `NACHRECHERCHE`.

**Produktion:** `KANDIDAT → IN_RECHERCHE → GEPRUEFT → kontrollierter JSON-Batch (max. 25) → Validator → WordPress-DRAFT → vollständiger Readback → manuelle Freigabe`. Kein Cron-Discovery, keine Auto-Publish- oder Loopback-Kette.
