## 6.72.8 Rootfix

1. Cleanup-Autorität
- terminale automation_runs-Zeile ist Autorität.
- provider=awin, partner_external_id=14336, operation=queued_partner_sync, status=failed.
- zusätzlich eindeutige Stop-Meldung "Alter/ungefilterter OTTO-Vollfeed...".
- portal_filtered-Runs sind ausgeschlossen.

2. Exakte Neuanlage-Provenienz
- last_complete_run muss exakt run_uuid sein.
- immutable first_seen muss zwischen started_at und finished_at des Fehl-Runs liegen.
- Kandidatenanzahl muss EXAKT run.imported entsprechen.
- run.updated muss 0 sein.
- jeder Mismatch => BLOCKED / keine Löschung.

3. Vollständiger Preflight vor Destruktion
- alle Kandidaten-IDs und identity_hash-Werte werden vollständig validiert, bevor der erste Write erfolgt.
- ungültige Identity => kompletter Run BLOCKED, keine Teilbereinigung.

4. Ausgabe
- verknüpfte Output-Objekte werden nicht gelöscht, sondern materialisiert deaktiviert und auf blocked_source gesetzt.
- Zielkanten werden nur über exakte identity_hash entfernt.
- Produktzeilen werden nur mit exakter id/provider/partner/source_kind/run_uuid/first_seen-Provenienz gelöscht.

5. Idempotenz / Sichtbarkeit
- cleaned_run_uuids werden gespeichert.
- zweiter Cleanup meldet already_cleaned und löscht nichts weiter.
- Backend zeigt OTTO-Sicherheitsbereinigung IMMER: pass / blocked / no_candidate / already_cleaned / nicht ausgeführt.
- kein matched_runs-Sichtbarkeitsfilter mehr.

6. Sicherheitsmigration
- target 4.1.3.
- bei erkanntem Cleanup-Kandidaten bleibt Automatisierung deaktiviert.
