PUBLIC DIGISTORE24 SUPPORTED-API EXHAUSTION — 2026-09-02
Official current Digistore24 OpenAPI/Swagger reference: https://www.digistore24.com/api/docs/index.html
The public Affiliates section exposes these relationship operations:
- getAffiliateCommission
- getCustomerToAffiliateBuyerDetails
- getReferringAffiliate
- getAffiliateForEmail
- setAffiliateForEmail
- setReferringAffiliate
- updateAffiliateCommission
- validateAffiliate
There is no listAffiliations/listAffiliatePartnerships/current-affiliate-partnership-inventory endpoint in the current public reference.

Cross-check against the current 122-endpoint typed client GoSuccessHQ/digistore24-api also reports complete Affiliate Management coverage with only the same affiliate-management family plus statsAffiliateToplist; no partnership-inventory list endpoint.

Endpoint semantics checked:
1) getAffiliateCommission
   - requires an affiliate ID; productIds is optional and may be comma-separated IDs or "all".
   - response contains affiliation rows per product with productId and approvalStatus.
   - This is commission/affiliation management for a specified affiliate against products in the API account context. Historical live evidence already showed that treating "all" as the user's affiliate-side foreign-vendor inventory did not yield the required inventory. Therefore it remains non-authoritative for discovery without new REAL counter-evidence.

2) validateAffiliate
   - requires affiliateName AND productIds.
   - It can verify known products, but cannot discover unknown partnership product IDs.

3) listMarketplaceEntries
   - returns marketplace entries, not the account's accepted-affiliation inventory.
   - Digistore24 Help Center explicitly describes marketplace entries as products vendors chose to publish on the marketplace and a place where affiliates request partnerships. Existing partnerships can exist independently of current marketplace publication. Therefore marketplace cannot be authoritative current partnership inventory.

4) listProducts
   - documentation says "Lists all products in your Digistore24 account".
   - It is account/vendor product inventory, not affiliate-side products of foreign vendors.

5) IPN on_affiliation
   - official IPN documentation describes the event when an affiliate wants to promote YOUR product and the affiliation is accepted.
   - It is a vendor-side future event stream, not a proven read-only backfill of the user's current affiliate-side vendor partnerships.

REAL UI FACT
Digistore24 Help Center states that Affiliate view -> Verkäufe & Partner -> Partnerschaften mit Vendoren shows the unfiltered list of all partnerships, including vendor, product/language, status, commission and advertising-media link. The real account screenshot established 18 results. The unauthenticated route https://www.digistore24-app.com/affiliate/account/affiliations redirects to Digistore24 login. No supported public API equivalent for that table was found in the current public API reference.
