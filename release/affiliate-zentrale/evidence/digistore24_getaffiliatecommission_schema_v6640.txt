CONCLUSION
The local V6.64.0 candidate is schema-compatible on the fields it uses:
- request: affiliate_id + product_ids
- response list: data.commissions
- row identity/state: product_id + product_is_active + approval_status + approval_status_msg

The candidate deliberately refuses `all` and limits automatic status checks to 1..50 explicit canonical product IDs. This is a local safety restriction, not an invented Digistore24 API requirement.
