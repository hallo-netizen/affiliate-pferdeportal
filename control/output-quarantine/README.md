# Output Quarantine

Fachblinde technische Ausgangssperre. Sie darf niemals Inhalt, Qualität, SEO, Design, Recherche oder Publish-Regeln bewerten oder verändern.

Nur Outputs, die durch einen gültigen gebundenen Step-Receipt mit exakt passenden SHA-256-Werten autorisiert sind, dürfen aus der Quarantäne in den freigegebenen Ausgabebereich gelangen.
